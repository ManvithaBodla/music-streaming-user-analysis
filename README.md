# Music Streaming User Analysis System

## Project Overview
This project analyzes Spotify music streaming data using SQL queries and business analytics techniques.

## Features
- Top popular songs analysis
- Top artists analysis
- Genre-wise analysis
- Danceability analysis
- High energy songs analysis
- Explicit vs non-explicit song analysis
- Average popularity analysis

## Dataset
The project uses a Kaggle Spotify dataset containing:
- Track names
- Artists
- Genres
- Popularity
- Danceability
- Energy
- Duration

## Tools Used
- MySQL Workbench
- SQL
- Microsoft Word
- GitHub

## SQL Queries Performed
1. Top Popular Songs
2. Top Artists
3. Genre-wise Song Count
4. Most Danceable Songs
5. High Energy Songs
6. Explicit vs Non-Explicit Songs
7. Longest Songs
8. Average Popularity by Genre

## Business Insights
- Popular songs attract more listeners.
- Genre trends influence listener preferences.
- Recommendation systems improve engagement.
- Danceability and energy affect song popularity.

## Conclusion
This project demonstrates SQL querying, business analysis, and real-world music streaming analytics using Spotify data.
