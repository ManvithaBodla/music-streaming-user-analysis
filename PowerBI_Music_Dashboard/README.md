# Spotify Music Dashboard

## Overview
This project presents an interactive Power BI dashboard built using Spotify music streaming data from Kaggle.

## Features
- KPI Cards
- Genre Popularity Analysis
- Explicit vs Non-Explicit Song Analysis
- Top Songs Table
- Genre Filters and Slicers
- Interactive Visualizations

## Tools Used
- Power BI
- SQL
- Kaggle Dataset
- Data Visualization

## Insights
- Popular genres show higher engagement trends
- Danceability and popularity influence streaming behavior
- Dashboard analytics help understand music trends effectively
